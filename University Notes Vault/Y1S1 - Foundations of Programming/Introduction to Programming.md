## Computer programs

A computer (CPU, GPU, NPU, QPU) does *exactly* what you tell it to do. A program is "how" you tell the computer what to do; its a se of percise instructions which (typically) solve a problem.

E.g a Calculator, video game, or even the entire OS.

## Algorithms

Algorithms are a "plan" for how a program works, its a step by step set of actions and options for how to solve a problem - it can be thought off as a flowchart.

## How to "talk" to a computer

Computers only understand Machine code (1's and 0's). Writing in this way is impossible for humans.

So we use programming languages that use words and syboles we can understand. These programs are then compiled into Machine Code (C, Rust) (what we call a binary).

Some languages are "transpiled" to an intermediate code(Java > bytecode > machine code), before being intepreted into machine code. Some languages are also just intepretted (Python).

## Programming Language Levels

High Level Languages (C Sharp, Python Java)

> Provides abstact commands, focuses on human usability
> Same code can be compiled for different machines.

Low Level Languages (C)

> Stop gap between HLL and AL, a mix of both worlds.
> High level of control over memory but still abstracted.

Assembly Language (ASM)

> Uses mnemonics to represent machine instructions
> Still more readable than machine code
> Very high level of control over hardware

Machine Language

> Language of the CPU
> Not human readable
