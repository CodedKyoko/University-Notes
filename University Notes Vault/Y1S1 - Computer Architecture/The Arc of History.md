## Who Invented the First Computer?

Church's Thesis: A computer is a machine that can simulate any other machine, given as much memory as it asks for.
So it must simulate machines that can; read, write and process data, read, write and execute programs. Perform arithmetic, jump around the code, and branch the code.

Ishango Bone - 20 BCE; Tally Stick - Basic Arithmetic.

Abacus - 2500 BCE; Accumulator Arithmetic / Basic Calculator.

Antikythera Mechanism - 100 BCE; Simulates Astronomical Motions.

- Odometry Cart - 50 CE; Used for measuring space with Units.

- Barrel Organs - 850 CE; Automated Music Player.

- Madrid Codex - 1502 CE; Mechanical Calculator.

- Pascals Calculator - 1652 CE; Carry Mechanism; Discrete Calculator.

- Jaquard Loom - 1804 CE; Punch card programs.

- Victoria Barrel Organ - 1800 CE to 1900 CE; Automated music player, programmed with pins (Representing notes), and later; punch cards.

- Difference Engine - 183 CE; Advanced Programmable Arithmetic - Programmed via Punch cards.

- Analytical Engine - 1836 CE; Capable of Add, Jump, Branch, Read programs from Paper, Tape or Cards. It has RAM/ Memory. STEAMPUNK. It uses a CISC (Complete Instruction Set Computer)-Type architecture. The user program was written on punch cards<--- This is the first computer.

#### Harvard Architecture

The analytical engine is Harvard architecture - programs and data is separated. 
You can use a Virtual Machine to to simulate a computer which does have re-programmable programs- aka Von Nueman Architecture.

### Electrical Machines

- IBM Hollerith Machine - 1890 CE; Electro-Mechanical Computer, uses both mechanical punch card systems, but are powered by electricity. Roughly capable of performing SQL Like database queries. Hollerith machines still often used today (and used extensively in WW2 for code cracking)

- Konrad Zuse - 1941 CE; First Electro-Mechanical General Purpose Computer. 2,000 relay switches, 5-10 instr./s, 64x22 bits of binary (mechanical memory). Perfectly fulfils requirements to be a Church Computer; Could potentially simulate Von-Neumann Architecture (just very slowly)

- Colossus Code Breaker - 1944 CE; First fully Electric Machine. Partially programmable (via rewiring), theoretically a Church Computer (Via a VM) Uses Binary.

- ENIAC - 1946 CE; Also Electronic Valve based; Harvard Architecture; Another unrealised VM potential - Also reprogrammed via switching Wires.
	
	- ENIAC VM - 1948 CE; Rediscovered in 2016; Ran a Von-Neumann VM. Only Programmable via Switches.

- Harvard Mk II - 1947 CE; First case of a Bug. Flying into relay 70 and making it blow up.

- Manchester Mark 1 "Baby" - 1948 CE; Program in RAM. Indisputably "Modern". Green CRT Matrix for RAM.
